# MAFSkirmishApp
Software package for Mobile to control and manage airsoft objective game cases.

Currently supports the following game modes.

- Domination
  Up to 4 teams fight over control of the devices, points are accumulated over time
  and game is won by the team with the highest score at the end of the timer or at a set limit.
  Allows point gain per team per node so different teams can earn more points for more dangerous/harder to control nodes.
  
- Search & Destroy
A classic bomb planting game more where you have an attacking team and a defending team.
The attackers win if they get to the site, arm the bomb and defend it for the duration of the timer.
Defenders win either by time or by defusing an active bomb.
